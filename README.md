Aethel Linux

Your PC Your choice

Overview

Aethel Linux is a minimal Linux distribution for people who want to choose what is installed and running on their computer. Start with a small base, understand your system, and build it around your needs.

The philosophy is simple: your system should contain the tools and services you choose. No preinstalled desktop environment or extra applications to remove before you can get started.

Aethel Linux is in early development. Expect bugs, unfinished features, and limited hardware support.

What Comes Next
Refine APM and expand its command set.
Build and host public package repositories.
Improve the base system and test on more hardware.

Longer-term ideas include Raspberry Pi and 32-bit editions. These would require architecture-specific packages, repositories, and compatibility work across the system.

Finit, BusyBox Init, S6, 66, Sysvinit, OpenRC, and dinit are also being considered as future init options alongside runit. Supporting them would require corresponding changes to ASMT.

These are future possibilities, not release commitments. Aethel Linux remains an early-stage project.
